# Classification d'Images de Fleurs
Ce projet vise à développer des algorithmes de classification en **C++** pour différencier les photos de roses, marguerites et tulipes. L'objectif est d'explorer et de mettre en œuvre différentes techniques d'apprentissage automatique pour parvenir à une classification précise.

## Structure du projet

- **.idea/**: Contient les paramètres spécifiques du projet pour l'IDE.
- **Flask_app/**: Contient l'application web Flask.
  - **static/**: Contient le logo et les images.
  - **templates/**: Contient les modèles HTML pour l'application web.
  - **\_\_init\_\_.py**: Initialise l'application Flask.
  - **app.py**: Le fichier principal pour exécuter le serveur Flask.
- **library/**: Inclut les bibliothèques externes utilisées dans le projet. (ml, mlp)
- **loaded_lib/**: Contient des bibliothèques supplémentaires chargées.
- **src/**: Contient le code source pour le traitement des données et l'entraînement du modèle.
  - **img/**: Répertoire pour les données liées aux images. (scraping, redimensionnées, vecteurs)
  - **Rapport_Interactif_pmc.ipynb**
  - **Rapport_Interactif_ML.ipynb** 
  - **dataset_scraping.py**: Script pour extraire le dataset.
  - **img_resize_vector.py**: Script pour redimensionner et vectoriser les images.
- **.gitattributes**
- **.gitignore** 
- **README.md**
- **requirements.txt**: Liste les dépendances nécessaires pour le projet.
